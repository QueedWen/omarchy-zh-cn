# 应用列表回退验证

关联问题：[#6](https://github.com/QueedWen/omarchy-zh-cn/issues/6)、[#3](https://github.com/QueedWen/omarchy-zh-cn/issues/3)。

宿主代理可能为空，也可能仍然存在但所属插件标识已丢失、缺少方法或访问时抛错。菜单检查代理有效性后再使用；不可用时复用当前系统的 AppLibrary 和 AppSearch 作为用户级备用实现。由于 QObject 销毁可能清空属性而不重新计算绑定，菜单打开时会重新检查，打开期间每 500 毫秒检查一次；应用库切换后重新生成已加载的应用列表。

## 自动化检查

运行 `./tests/smoke.sh`。覆盖空接口、正常代理、无 owner 的失效代理、缺少方法、访问抛错及宿主替换。存在桌面会话时，还运行真实 QML 测试，创建并销毁 QObject 代理，验证本地回退自动生效；无桌面会话时明确跳过这一项。

## 实机验证

在 Omarchy 4.0.6-1 上，移除手动固定入口后，自动收录 43 个可见应用，包含 Clash Verge 和 ChatGPT。插件重扫、桌面 Shell 重启后均重新读取应用行并通过搜索评分检查，Hyprland 配置无错误。没有执行整机重启测试，也未通过测试自动启动或卸载应用。

## 4.0.3 的验证范围

检查官方 v4.0.3 标签：Menu.qml 的应用库接入点及所需方法均存在，AppLibrary.qml 和 AppSearch.js 与本机 4.0.6-1 的对应文件完全相同。补丁在源码层面适配，但这不等价于 4.0.3-1 的完整实机验证。#3 仍需对应版本用户更新后确认，不应仅凭本机结果关闭。
